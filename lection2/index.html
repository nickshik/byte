1. Что такое CSS и синтаксис

CSS — это язык стилей, который отвечает за внешний вид сайта (цвета, шрифты, отступы). Код состоит из правил. Сначала пишется селектор (что красим), а в фигурных скобках {} — свойства и значения через двоеточие.

2. Как подключить CSS

Стили можно задать тремя способами: внутри тега через атрибут style, в голове документа в теге <style> или в отдельном файле style.css. Третий способ — лучший, он подключается в <head> через тег <link rel="stylesheet" href="style.css">.

3. Селекторы: тег, класс, id

Селекторы находят элементы на странице. Можно выбрать все теги (например, p {}), конкретный класс через точку (.button {}) или уникальный идентификатор через решетку (#header {}). Классы используются чаще всего.

4. Цвет и фон

Свойство color меняет цвет текста, а background-color задает фон элемента. Цвета можно указывать словами (red), HEX-кодом (#ff0000) или в формате rgb(255, 0, 0). Для прозрачности используют rgba().

5. Шрифты и текст

Размер текста управляется свойством font-size (например, 16px). Семейство шрифта задается через font-family, а жирность — через font-weight: bold. Выровнять текст по центру можно с помощью text-align: center.

6. Размеры и Блочная модель

Каждый элемент на странице — это прямоугольная коробка. Мы задаем ей ширину width и высоту height. Также у нее есть внутренние отступы padding (до контента) и внешние отступы margin (расстояние до соседних блоков).

7. Рамки и Скругления

Свойство border создает рамку вокруг элемента, где указывается толщина, стиль и цвет (например, 2px solid black). Чтобы сделать углы круглыми или превратить квадрат в круг, используют border-radius.

8. Выравнивание через Flexbox

Чтобы легко расставить элементы в ряд или по центру, родителю дают свойство display: flex. Свойство justify-content выравнивает элементы по горизонтали, а align-items — по вертикали. Это главный инструмент современной раскладки.

9. Сетки CSS Grid Layout

Если Flexbox идеален для одномерных строк, то display: grid управляет двухмерными сетками (строки + колонки). Свойство grid-template-columns делит блок на столбцы, а gap задает удобные расстояния между ячейками сетки.

10. Свойство position

Свойство position вырывает элемент из общего потока. relative сдвигает блок относительно его обычного места, absolute привязывает его к координатам родителя, а fixed фиксирует на экране при скролле (например, шапку).

11. Псевдоклассы и Интерактив

Псевдоклассы меняют стили при действиях пользователя. Селектор :hover срабатывает при наведении курсора мыши, :active — в момент клика, а :focus — когда мы встаем внутрь текстового поля ввода input.

12. Медиазапросы @media

Чтобы сайт красиво отображался на телефонах, используют медиазапросы. Конструкция @media (max-width: 768px) позволяет написать отдельные CSS-правила, которые включатся только на небольших экранах смартфона или планшета.

13. Приоритеты и каскад

Браузер читает стили сверху вниз. Если правила конфликтуют, применится то, что написано ниже. Однако селекторы по ID сильнее классов, а классы сильнее обычных тегов. Самый высокий приоритет имеет метка !important.

14. Кастомные переменные

Чтобы не копировать один и тот же цвет сотни раз, используют переменные. Они объявляются через две черточки: --main-color: #3498db; внутри селектора :root. Вызвать эту переменную в нужном месте можно с помощью функции var(--main-color).

15. Плавность и Анимация

Свойство transition позволяет делать изменения стилей (например, цвета кнопки при наведении) плавными, а не мгновенными. Мы указываем анимируемое свойство, время анимации и характер изменения скорости, например: transition: background-color 0.3s ease.

16. Эффекты теней

Для добавления объема интерфейсу применяются тени. Свойство box-shadow настраивает тень для блочных элементов (смещение по X и Y, размытие, растяжение и цвет), а text-shadow создает красивый и глубокий теневой эффект непосредственно для букв текста.
